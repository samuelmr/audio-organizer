A target says where a library goes: a bucket on AWS S3 or an S3-compatible service (MinIO, Backblaze, Wasabi…), and optionally a folder (prefix) inside it. Tracks keep their library paths below the prefix, with their metadata as object metadata; playlists go to playlists/. Credentials are never stored here: they come from the AWS environment variables or ~/.aws, or from the named profile.
