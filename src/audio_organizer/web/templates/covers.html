Covers

Phones, car stereos and many players only show covers embedded in the files. These album folders have a cover image, and tracks without an embedded cover. Embedding copies the image into every such track, so a large image makes every file bigger; undoing the changeset removes the embedded covers again.

If the catalog was made before cover detection, run aorg scan --reread once; until then, files that already have a cover are left as they are when the changes are applied.
